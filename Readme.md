# Nguyen Cong Dat — Personal Homepage

A zero-build research portfolio for Nguyen Cong Dat, built with semantic HTML, modern CSS, and a small vanilla JavaScript layer.

## Local preview

Open `index.html` directly, or serve the directory with any static server:

```bash
python -m http.server 8000
```

The site is designed for GitHub Pages and has no package dependencies or build step.
